# StudyMate — النسخة المستقلة

## التشغيل السريع

افتح `api.config.js` في محرر نصوص محلي، ثم ضع مفاتيحك في `gemini.apiKeys` أو `openrouter.apiKeys`، وحدد `activeProvider`. بعد الحفظ افتح `index.html` في متصفح حديث. لا يلزم خادم محلي لهذه النسخة.

## تنبيه أمني

لأن هذه نسخة تعمل داخل المتصفح فقط، سيكون أي مفتاح تحفظه في `api.config.js` قابلًا للقراءة لكل شخص يحصل على نسخة من المجلد. لا تشارك الملف بعد ملء المفاتيح، ولا ترفعه إلى GitHub أو التخزين السحابي العام. الأفضل استخدام مفاتيح منفصلة ذات حدود استخدام مناسبة لهذه النسخة المحلية.

## إعدادات النماذج

يمكنك تغيير أسماء النماذج وقائمة المفاتيح من `api.config.js` من دون تعديل `index.html`. يبدأ التطبيق بالتبديل بين مفاتيح المزوّد المحدد، ثم ينتقل إلى المزود الآخر إذا كان مهيأً. لا توجد مفاتيح مضمّنة في الحزمة.

## قيود النسخة المحلية

قد تمنع بعض المتصفحات أو الشبكات الطلبات المباشرة لبعض مزودي الذكاء الاصطناعي بسبب إعدادات CORS أو سياسات المؤسسة. في هذه الحالة جرّب متصفحًا حديثًا أو مفتاحًا من المزود الذي يدعم الاستدعاء المباشر من المتصفح. لا تضف المفتاح إلى `index.html`.

## ملفات الحزمة

| الملف | الغرض |
|---|---|
| `index.html` | التطبيق الكامل والواجهة الاحترافية |
| `api.config.js` | إعداد مفاتيحك ونماذجك محليًا |
| `api.config.example.js` | قالب إعداد آمن للنسخ |
| `QUALITY.md` | تقرير تحسين جودة التوليد والمناهج |
